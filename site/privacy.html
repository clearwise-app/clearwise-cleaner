Политика конфиденциальности

Действует с 23 октября 2026 года. Относится к Clearwise Cleaner, Clearwise Lite и этому сайту.

Коротко

Clearwise не собирает, не хранит и не передаёт ваши данные. Никому, ни в каком виде.

Приложение

  • Приложение работает без интернета. В нём нет аналитики, телеметрии, рекламы и отчётов о сбоях, отправляемых разработчику.
  • Сканирование файлов, проверка аккумулятора и SSD и все прочие расчёты выполняются на вашем Mac. Результаты никуда не уходят.
  • Настройки (язык, режим очистки, выбранные папки) хранятся локально, в настройках macOS на вашем Mac.
  • Полный доступ к диску нужен только для того, чтобы найти мусор в закрытых папках. Он не даёт приложению возможности что-то отправить.
  • MCP-сервер clearwise-mcp общается только с программой-ассистентом на вашем Mac, которую вы подключили сами. Что ассистент делает с ответами, определяет его собственная политика.

Сайт

  • На сайте нет счётчиков посещений, cookies и сторонних скриптов.
  • Сайт размещён на GitHub Pages, а файлы для скачивания — в GitHub Releases. GitHub может записывать технические данные запросов, например IP-адрес, по своей политике конфиденциальности.

Если вы пишете нам

Если вы сами отправите сообщение в GitHub Issues или по почте, мы увидим то, что вы написали, и используем это только для ответа. GitHub Issues публичны, не публикуйте там личные данные.

Изменения

Если политика изменится, новая версия появится на этой странице с новой датой. История изменений видна в репозитории на GitHub.
