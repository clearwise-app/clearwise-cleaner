Privacy Policy

Effective October 23, 2026. Covers Clearwise Cleaner, Clearwise Lite and this website.

In short

Clearwise does not collect, store or transmit your data. Not to us, not to anyone.

The app

  • The app works offline. It has no analytics, telemetry, ads or crash reports sent to the developer.
  • File scans, battery and SSD checks and every other calculation run on your Mac. Results never leave it.
  • Settings (language, cleanup mode, chosen folders) are stored locally in macOS preferences on your Mac.
  • Full Disk Access is only used to find junk in protected folders. It does not let the app send anything anywhere.
  • The clearwise-mcp server talks only to the assistant app on your Mac that you connected yourself. What that assistant does with the answers is governed by its own policy.

The website

  • This site has no visit counters, cookies or third-party scripts.
  • The site is hosted on GitHub Pages and downloads are served from GitHub Releases. GitHub may log technical request data such as IP addresses under its privacy statement.

If you contact us

If you send us a message through GitHub Issues or email, we see what you wrote and use it only to reply. GitHub Issues are public, so please keep personal data out of them.

Changes

If this policy changes, the new version will appear on this page with a new date. The change history is visible in the GitHub repository.

Contact

Privacy questions: see the support page.
