# MacCleaner

Нативное приложение для macOS (SwiftUI, macOS 15+) для очистки диска. Разбор конкурентов — в [docs/competitors.md](docs/competitors.md).

![Умная очистка](docs/screenshots/1-smart-care.png)
![Выбор, что удалить](docs/screenshots/1b-smart-care-review.png)

## Модули

| Модуль | Что делает |
|---|---|
| **Умная очистка** | Сначала скан и обзор: что нашлось и сколько занимает. Затем шаг «Выбрать»: по каждой категории и каждому файлу решаете, что удалить, а что оставить («будет удалено X · останется Y»). Только после этого «Очистить» с подтверждением |
| **Системный мусор** | Кэши приложений и браузеров (без истории, паролей и cookies), логи, отчёты о сбоях, Xcode/DerivedData, кэши npm/pip/Homebrew/Gradle и других менеджеров, временные файлы, старые установщики, вложения Почты, бэкапы iPhone, сломанные настройки и агенты запуска, Корзина |
| **Деинсталлятор** | Удаляет приложение вместе со всеми следами: Application Support, кэши, настройки (в том числе ByHost), контейнеры и групповые контейнеры, сохранённое состояние, cookies, WebKit, HTTPStorages, LaunchAgents/Daemons, PrivilegedHelperTools, плагины, квитанции установщика, отчёты о сбоях, временные папки. Вкладка **«Остатки»** — следы приложений, которые уже удалены. Приложение можно перетащить в окно |
| **Старые и большие файлы** | Файлы, которые не открывались 3–24 месяца (по дате последнего открытия в Spotlight), и самые большие файлы. Ничего не выбирается автоматически |
| **Дубликаты** | Одинаковые файлы, найденные по содержимому (размер → хеш начала → полный хеш). У каждой копии переключатель «Оставить / Удалить»; по умолчанию остаётся самая старая копия вне Загрузок. Удалить все копии файла нельзя: одна всегда остаётся |
| **Карта диска** | Диаграмма-«солнце» в стиле DaisyDisk: щелчок открывает папку, найденное складывается в «Сборщик» |

## Безопасность

- Всё удаляется **в Корзину**, кроме очистки самой Корзины — об этом приложение предупреждает отдельно.
- Все удаления проходят через одну функцию, `FileRemover`. Она отказывается трогать системные пути, папки пользователя, Связку ключей, Почту, Сообщения, iCloud, медиатеки, данные встроенных приложений Apple и встроенные приложения.
- Остатки, совпавшие с приложением неточно, по умолчанию не отмечаются. Перед удалением виден полный путь каждого файла.
- Файлы, требующие прав администратора, переносятся после одного системного запроса пароля.

## Сборка

```bash
scripts/build_app.sh
```

Готовое приложение появится в `build/MacCleaner.app`. Для полного сканирования дайте ему **Полный доступ к диску**: Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску. Без этого доступа часть папок пропускается, а размеры контейнеров не считаются.

Тесты:

```bash
swift test
```

## Структура

- `Sources/CleanerKit` — модели, безопасное удаление, защита путей
- `Sources/JunkEngine` — поиск мусора
- `Sources/UninstallEngine` — список приложений, поиск их следов, удаление
- `Sources/SpaceEngine` — старые и большие файлы, карта диска, дубликаты
- `Sources/MacCleaner` — интерфейс. С флагом `--snapshot <папка>` приложение сохраняет скриншоты всех экранов
